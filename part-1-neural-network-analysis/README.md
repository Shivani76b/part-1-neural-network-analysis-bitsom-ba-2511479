## Dataset
Customer Churn Prediction dataset with 2000 rows and 17 columns.

## Problem Type
Binary Classification - Predicting whether a customer will churn or not.

## Tasks Completed
- Task 1: Dataset Understanding and Exploration
- Task 2: Data Preprocessing and Feature Scaling
- Task 3: Neural Network Model Building
- Task 4: Training and Evaluation
- Task 5: Hyperparameter Experimentation
- Task 6: Final Reflection

## Model Architecture
- Input Layer: 15 features
- Hidden Layer 1: 32 neurons, ReLU activation
- Hidden Layer 2: 16 neurons, ReLU activation
- Output Layer: 1 neuron, Sigmoid activation

## Results
- Training Accuracy: ~96%
- Validation Accuracy: ~95%
